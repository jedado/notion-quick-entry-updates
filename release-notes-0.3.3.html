Quick Entry is now Threadoak

  • A new layered app icon and a matching monochrome menu-bar mark.
  • The capture Settings pane is now called Task Capture.
  • Your existing capture settings and optional Meeting Sync setup keep their established identities.
  • Additional protection against running duplicate copies.

When updating an existing installation, the file in Applications keeps its current Quick Entry.app name while the app displays Threadoak. The file rename is a separate attended step; this update does not perform it automatically.

Keep Meeting Sync enabled on only your designated sync Mac. Updating another Mac does not enable its sync.

This personal release uses Apple Development signing; it is not a notarized Developer ID release.

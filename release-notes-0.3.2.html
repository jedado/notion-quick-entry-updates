Quick Entry 0.3.2

  • One Task form replaces the Action and Discussion split.
  • Task capture uses the selected database’s current default template and preserves your other form settings.
  • Meeting Sync brings selected Apple Calendar meetings into Notion, with scheduling, a bounded sync range, pause and resume, and activity history.
  • Unified Settings shares one Notion connection across task capture and Meeting Sync.

Enable Meeting Sync on only one Mac for a shared destination. Updating another Mac does not enable its sync.

This personal release uses Apple Development signing; it is not a notarized Developer ID release.
